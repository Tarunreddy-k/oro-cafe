# Mattino Oro Café — Demo Website

A premium, responsive restaurant website concept tailored to Mattino Oro Cafe, AECS Layout, Bengaluru.

## Run
Open `index.html` directly in a browser, or deploy the folder to Vercel/Netlify/GitHub Pages.

## Notes
- Public business details were used for the demo: name, location, phone, broad cuisine/menu categories and hours.
- Menu prices/content are a website-demo presentation and should be verified with the restaurant before publishing.
- Photography uses remote Unsplash URLs; replace with the restaurant's own licensed photos for production.
